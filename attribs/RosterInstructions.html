RaidHelper Import

✅ This is a great option for Pug/GDKP raids, where the roster fluctuates heavily and you need a way to quickly import the roster each week.

⚠️ Roster your players in the "Composition Tool" before beginning the import process. Find the tool by going to the event in Discord and clicking "Comp" at the bottom of the signup. The import will fail with no players in the composition.

▶ Click the "Import Using RaidHlper ID" button, paste your RaidHelper ID in the field provided and click "OK". You can find your RaidHelper ID at the end of the Comp URL as shown here: raidhelper.dev/raidplan/12345678910.

▶ You will still need to manually assign any Flex Specs and adjust any character names that don't exactly match the in-game ones.

Group Builder / Split Manager Import

✅ This is a great option for guilds that have multiple rosters and want to manage each of them seperately each week.

⚠️ Upon first copy, you will need fill out your full Guild Roster in the "Guild Manager" tab, including their alts and off-specs where necessary.

▶ Slot in your players and their alts into the corresponding raid groups in the "Group Builder" tab, ensuring to select who will be flexing to tank and healer in the "Flex Roles" section.

▶ View which players/alts you have available, where they're rostered and if you have any roster conflicts in the "The Guild Overview" section.

▶ Use the buttons provided on either the "Group Builder" page or the "Roster" page to then load the split that you would like to manage assignments for.

▶ You can save your roster and your assignments (once filled out) for use later using the "Save" button.

▶ Load saved rosters/assignments for each split using the "Load" button.

Manual Roster Import

✅ This is a great option for guilds that only have one roster, and wish to just use the checkboxes to roster/bench players on a week-to-week basis.

⚠️ Upon first copy, clear the template roster by using the "Clear Roster" button on the Roster page.

▶ Simply type or paste in your Raider's character names with CTRL + ALT + V. If you're using our Fojji Raid CD integration, these names need to match the player's in-game name exactly.

▶ Assign their Class/Spec/Flex Spec using the dropdowns provided.

▶ Roster your players by clicking the Checkboxes in the "Is Rostered" column.
