RaidHelper Import

✅ A great option for Pug/GDKP raids, where the roster changes heavily and you need to import it quickly each week.

⚠️ Roster your players in the "Composition Tool" before starting the import. Find the tool by going to the event in Discord and clicking "Comp" at the bottom of the signup. The import fails when the composition has no players.

▶ Click the "Import" button, paste your RaidHelper ID in the field provided and click "Import". Your RaidHelper ID is at the end of the Comp URL: raidhelper.dev/raidplan/12345678910.

▶ You still need to set any Flex Specs by hand, and fix any character names that don't exactly match the in-game ones.

Manual Roster Import

✅ A great option for guilds with a single roster that use the checkboxes to roster/bench players week to week.

⚠️ On a fresh copy, clear the template roster with the "Clear Roster" button on the Roster page.

▶ Type or paste your raiders' character names with CTRL + SHIFT + V. For the Fojji WeakAura exports, these names must match the in-game names exactly.

▶ Set their Class/Spec/Flex Spec with the dropdowns provided.

▶ Roster your players with the checkboxes in the "Is Rostered" column.
